부산대 PLATO를 위한 MCP 서버 설치하기

아래에 학번/비밀번호를 입력하면 Claude.ai, Claude Code, Codex CLI 등 사용 중인 클라이언트에 바로 붙여넣을 수 있는 연결 명령어를 만들어 드립니다. 입력한 값은 이 브라우저 밖으로 전송되지 않습니다.

연결 전에 꼭 읽어주세요. 이 서버는 PLATO에서 이미 볼 수 있는 내용 (다른 학생 이름이 포함된 Q&A 게시글 등)을 AI와의 대화로 그대로 전달합니다. 자세한 내용과 전체 기능 목록은 README의 면책조항과 개인정보 안내를 참고하세요.

설치 명령어 생성기

사용 중인 클라이언트를 고르고, 학번/비밀번호를 입력하면 바로 복붙 가능한 설정이 만들어집니다.

입력값은 서버로 전송되지 않습니다. 이 생성기는 브라우저 안에서만 동작하는 순수 텍스트 치환 도구입니다 — 새로고침하면 입력한 값은 사라지며 어디에도 저장되지 않습니다. 생성된 명령어 자체에는 비밀번호가 평문으로 들어가므로, 복사한 내용을 스크린샷이나 채팅으로 공유하지 않도록 주의하세요.

FAQ

Glama에 "This server cannot be deployed"라고 나와요.

Glama에는 이 서버의 리스팅이 두 개 있습니다 — GitHub를 직접 크롤링한 구버전 리스팅과, 공식 MCP Registry를 통해 들어온 리스팅. 전자에서만 뜨는 표시이고 무시해도 됩니다. 공식 레지스트리 쪽(connectors)에는 이미 품질 평가가 끝나 정상적으로 표시되어 있습니다.

연결 후 첫 호출이 30초~1분씩 걸려요.

서버가 Render 무료 플랜에서 돌고 있어 15분간 요청이 없으면 잠듭니다. 첫 호출에서 깨우는 시간이 걸리는 것이며 오류가 아닙니다 — 두 번째 호출부터는 빨라집니다.

비밀번호가 서버에 저장되나요?

저장되지 않습니다. 요청을 처리하는 동안만 메모리에 존재하며 디스크에 쓰지 않습니다. 자세한 내용은 SECURITY.md를 참고하세요.
